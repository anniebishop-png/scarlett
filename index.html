Bulk add tasks

Paste rows straight from Excel or Google Sheets, or type one task per line. Columns can be separated by tab (a normal spreadsheet paste) or comma:
Client, Date, Title, Team, Owners, Status, Tag — only Client, Date and Title are required.
Dates: 2026-09-16, 9/16/2026, 9/16, or a day name like Wed (matched to whichever week you're currently viewing). Multiple owners: separate with /.

Bulk add shows

Paste rows straight from a spreadsheet, or type one show per line. Columns, separated by tab or comma:
Event, Date, Discipline, Client, Delivery items, Client Ops — only Event and Date are required. Leave Client blank for a reference-only show.
Dates: 2026-09-16, 9/16/2026, 9/16, a day name like Wed, or W/O 9/14 for "week of" (any day in that week works). Multiple clients or delivery items: separate with /.
Client Ops: Yes or No (defaults to Yes when there's a client). Only matters if a Client is set — sets up kickoff/reporting/invoicing tracking automatically.

What kind of client is this?

Long-term clients like Red Mills or Highlands Cup get their own set of contracted deliverable categories, with targets you define once — the tracker then counts delivered items against them. A one-off show client just logs items against the general category list, no contract needed.

Set up contract categories

One deliverable category per line, in the order you want them to appear on the tracker. Add a target count after a comma if the contract specifies one, e.g. Podcast Episode, 10 — or leave it off to just track delivered/not with no fixed count, e.g. Website Sport Update.
